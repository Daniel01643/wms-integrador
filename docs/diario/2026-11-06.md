### Correções de robustez (causa dos 401)
- **TLS 1.2**: forçado no handler do HttpClient (SocketsHttpHandler + Tls12/Tls13). O 2012 R2
  não negociava TLS 1.2 de forma consistente; era a causa dos 401 em massa.
- **GetToken resiliente**: retry com backoff para 401/5xx transitório, para não derrubar o
  pacote inteiro quando o token falha esporadicamente.
- Resultado: lote grande integrado sem 401; resíduos antigos reprocessados com sucesso.
